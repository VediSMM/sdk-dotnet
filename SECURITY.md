# Security policy

## Supported versions

Security fixes are provided for the latest released minor line. Version `0.1.x` is currently supported.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/VediSMM/sdk-dotnet/security/advisories/new). Do not open a public issue with exploit details, credentials, tokens, webhook secrets, or personal data.

Include the affected version, impact, a minimal reproduction, and any suggested mitigation. We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

Never use production credentials in a report. Revoke any credential that may have been exposed.
